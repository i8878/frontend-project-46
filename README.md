### Требования:

* UNIX OS
* Nodejs 20.19.2+
* Make

### Описание:

Утилита сравнивает содержимое двух файлов в формате .json или .yml, и выводит результат в одном из трёх возможных вариантов:
* stylish
* plain
* json

### Установка:

```bash
make install
```

```bash
make publish
```

```bash
sudo npm link
```
